# EigenPlaces BPU model

`eigenplaces_r18_512_480x640_bayes_e.bin` is the Horizon BPU deployment form
of the EigenPlaces ResNet18-512 model used by the RDK X5 visual place
recognizer. The upstream EigenPlaces implementation is MIT licensed:
https://github.com/gmberton/EigenPlaces

The runtime requires an RDK X5 installation that provides `hbm_runtime`.
