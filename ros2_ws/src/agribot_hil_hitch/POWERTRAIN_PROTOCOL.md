# 传动台架 ISOBUS 与原生 CAN 协议

本协议是隔离 HIL 台架的自定义应用扩展，版本 `0x22`，与原悬挂 `0x21` 并行。采用 AgIsoStack++ 地址声明和对端 NAME 校验；下面的 PGN/数据定义不等同于标准 TIM、UT、TC 功能，不构成 ISOBUS 互操作认证。

两段总线均为经典 CAN、250 kbit/s。多字节字段为小端，全部载荷 8 字节，最后一字节为 CRC-8/SAE-J1850：多项式 `0x1d`，初值和最终异或均为 `0xff`，只计算前七字节；校验向量 `123456789` 为 `0x4b`。除状态帧外，计数器用于重复/倒序判断，并允许正常回绕。

## 上游 ISOBUS PGN

X5 端点首选地址 `0x94`、身份 `0xb71`，6750 首选地址 `0x95`、身份 `0xb72`，厂家码 2047；均为实验身份。指定目的地址时应使用声明后的实际地址，而不是盲信首选地址。非预期 NAME 的控制指令不执行。

### EF00 传动模式指令

`EF00` 是指定对端的 PDU1 PGN。字节 0 为 `0x21` 时仍交原悬挂控制器处理；为 `0x22` 时按下面的传动格式处理：

| 字节 | 字段 | 编码 |
| --- | --- | --- |
| 0 | 版本 | `0x22` |
| 1 | 模式 | 0 停止，1 手动动力换挡，2 自动动力换挡，3 自动 CVT，4 手动 CVT |
| 2 | 手动挡位 | 模式 1 为 1 至 4，其他模式为 0 |
| 3 | 转速请求 | rpm / 20，允许 800 至 2200 rpm |
| 4 至 5 | CVT 手动总减速比 | 比值 ×10，模式 4 为 2000 至 9000，其他模式为 0 |
| 6 | 指令计数器 | uint8 |
| 7 | CRC | 前七字节的 CRC |

500 ms 内的新指令必须为前向计数器。非停止模式需先收到显式停止预热；实际车速绝对值超过 0.03 m/s 时拒绝改变模式，但允许同模式内调整挡位、转速请求或手动 CVT 速比。

### FF73 参数设置

| 字节 | 字段 | 编码 |
| --- | --- | --- |
| 0 | 版本 | `0x22` |
| 1 | 换挡交接时间 | 时间 /10 ms，20 至 200 |
| 2 至 3 | CVT 速比变化率 | 比值单位/s ×10，100 至 3000 |
| 4 至 5 | 保留 | 必须为 0 |
| 6 | 设置计数器 | uint8，与模式指令分开计数 |
| 7 | CRC | CRC |

设置改变仅允许实际车速绝对值不超过 0.03 m/s。连续发送相同设置可以保持应答。协议提供设置请求的处理应答；目前没有单独的设置回读 PGN，不应把应答描述为完整配置回读校验。

### 反馈与应答

| PGN | 数据 |
| --- | --- |
| `FF74` | 原生 `642` 的发动机反馈原载荷 |
| `FF75` | 原生 `643` 的速比/离合器压力原载荷 |
| `FF76` | 原生 `644` 的车辆反馈原载荷 |
| `FF77` | 原生 `645` 的负载反馈原载荷 |
| `FF78` | 版本、实际控制模式、TCU挡位、请求挡位、换挡阶段、故障位、输出序号、CRC |
| `FF79` | 版本、处理结果、请求模式、请求挡位、指令种类、保留0、请求计数器、CRC |

`FF79` 的种类 0 为模式指令，1 为参数设置。处理结果 0 成功、1 格式/CRC错误、2 范围错误、3 重复/倒序、4 未显式停止预热、6 行驶时改变模式或设置。6750 故障位：bit0 超时/未就绪，bit1 传感故障，bit2 超速。换挡阶段为 0 稳定、1 充油、2 交接。`FF78` 每 100 ms 发布。

## 下游标准 CAN 帧

原 `620`、`621`、`630`、`631` 格式不变。`620` 速度作为新 TCU 车速需求；原后轮速度控制的最大转矩为零，只保留既有转向和里程计链路。

### 640 发动机与离合器 A 控制

| 字节 | 字段 |
| --- | --- |
| 0 至 1 | uint16 油门，0 至 1000 对应 0 至 100% |
| 2 至 3 | uint16 离合器 A 请求，0 至 1000 |
| 4 | bit0至2 模式，bit3 使能，bit4 制动，其余位必须为0 |
| 5 | 版本 `0x22` |
| 6 | 执行计数器 |
| 7 | CRC |

### 641 传动与离合器 B 控制

| 字节 | 字段 |
| --- | --- |
| 0 至 1 | uint16 请求总减速比 ×10 |
| 2 至 3 | uint16 离合器 B 请求，0 至 1000 |
| 4 | 低4位离合器A支路挡位，高4位离合器B支路挡位，各0至4 |
| 5 | 版本 `0x22` |
| 6 | 与640相同的执行计数器 |
| 7 | CRC |

PC 必须收到计数器相同、组包跨度不超过 100 ms 的两帧，才原子更新执行命令。报文租约为 200 ms；首次及超时后需要中位制动帧。无使能时模式、油门和两离合器均应为零；制动时两离合器应为零。

### 642 至 645 仿真传感反馈

| ID | 字节0至1 | 字节2至3 | 字节4至5 | 字节6 |
| --- | --- | --- | --- | --- |
| `642` | uint16 发动机rpm | uint16 输入轴rpm绝对值 | int16 输入转矩 N·m ×10 | 采样计数器 |
| `643` | uint16 总减速比 ×10 | uint16 A实际压力 kPa | uint16 B实际压力 kPa | 同组计数器 |
| `644` | int16 车速 mm/s | int16 输出轴rpm ×10 | 字节4低4位实际挡位、高4位实际模式；字节5传感故障 | 同组计数器 |
| `645` | uint16 注入负载 N | 字节2发动机负载百分比；字节3制动状态 | 字节4使能；字节5版本22 | 同组计数器 |

最后一字节均为 CRC。`642` 至 `644` 构成控制所需原子传感组合，三个计数器相同、组包跨度不超过 100 ms 才刷新控制器传感有效期。`645` 用于监视，不参与传感有效期刷新。PC 发布周期为 20 ms。

动力换挡的总减速比反馈按两离合器实际压力加权，交接阶段为等效值，不代表两种齿轮刚性同时啮合。CVT 的总减速比反馈为受执行速率限制的实际比值。实际挡位根据占优离合器支路确定；CVT 挡位字段为 0，不能据此判断其是否停止。

## 上层话题和记录

`/hil_hitch/powertrain/command` 为高层完整 JSON 指令。`/hil_hitch/powertrain/status` 为 X5 收到的 ISOBUS 最新快照，每项含 X5 本地单调时间和 8 字节十六进制载荷。监视订阅必须使用 best effort；可靠慢订阅者不能阻塞控制循环。

PC 独立物理记录 `/hil_hitch/powertrain/plant_state` 为 20 个数值，顺序为：

```text
模式, 发动机rpm, 输入轴rpm, 输出轴rpm, 实际总减速比,
A压力kPa, B压力kPa, 油门0至1, 输入转矩Nm, 总后轮转矩Nm,
实际前向车速m/s, A支路挡位, B支路挡位, 实际挡位,
负载N, 制动, 发动机与输入轴滑差rpm, 仿真时间s,
请求总减速比, 使能
```

PC 与 X5 的系统墙钟不同，跨机延迟不能直接用两侧时间戳相减。报文对应关系用帧 ID、载荷、计数器和 CRC 核对；控制租约使用各端本地单调时间。
